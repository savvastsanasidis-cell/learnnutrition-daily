⚠️ Σημείωση εκτέλεσης (cloud environment): Σήμερα το περιβάλλον cloud είχε αποκλεισμένη πρόσβαση στο YouTube. Όλες οι δίοδοι δεδομένων — επίσημα RSS feeds, σελίδες βίντεο, transcripts, το YouTube Data API (googleapis χωρίς κλειδί) και τα third-party mirrors (Piped, Invidious, Socialblade, rss2json) — επέστρεψαν 403 / εκτός allowlist. Η ανίχνευση νέων βίντεο έγινε επομένως μόνο μέσω web search, του οποίου το ευρετήριο υστερεί για τα πιο πρόσφατα uploads. Κανένα νέο βίντεο 24ώρου δεν επιβεβαιώθηκε με βεβαιότητα. Παρακάτω αναφέρεται το πιο πρόσφατο γνωστό βίντεο ανά κανάλι. Για πλήρη λειτουργία (transcripts + fact-check), τρέξε τη ροή από περιβάλλον με το youtube.com / googleapis.com (με YouTube Data API key) στο network allowlist.
